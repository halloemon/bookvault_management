📚 Book Inventory Management System
📖 Project Description

The Book Inventory Management System is a simple Python application developed to manage a collection of books. It allows users to add, view, search, update, sell, and delete books through a menu-driven interface. The project demonstrates basic Python programming concepts and inventory management.

✨ Features


➕ Add a new book to the inventory
📋 Display all available books
🔍 Search for a book by name
💰 Sell a book and reduce its quantity
✏️ Update the quantity of a book
🗑️ Delete a book from the inventory
❌ Exit the application safely
